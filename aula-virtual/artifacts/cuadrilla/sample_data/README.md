# Clase de prueba

Coloca aquí el transcript de la master class «Python para analistas: automatiza tus reportes»
(archivo `.md` o `.txt`). Salvo este README, el contenido de la carpeta no se versiona en Git.

- Con `DEMO_MODE=true`, la pantalla **Subir clase** ofrece «Usar el transcript de ejemplo»: la clase
  pasa por el flujo real (anonimizar, mapear a la malla, pregenerar 4 retos) y necesita la clave del
  proveedor de IA configurado (`OPENAI_API_KEY` o `GOOGLE_API_KEY`).
- El botón **Cargar datos de demostración** del administrador usa este transcript (o un texto breve si
  no existe) con retos escritos a mano, sin llamar a la IA.

Formatos que acepta **Subir clase**: `.mp4`, `.mov`, `.webm`, `.mp3`, `.wav`, `.m4a` (se transcriben con
el proveedor configurado) y `.txt`, `.vtt`, `.md` (se leen directamente).
